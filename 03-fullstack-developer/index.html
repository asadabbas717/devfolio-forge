About

One product, not separate “front” and “back” problems.

My favorite work sits where product decisions meet engineering trade-offs: the moment a user interaction becomes API behavior, database state, or operational responsibility.

This sample profile uses React and Next.js for interface work, Node.js and Express for services, PostgreSQL or MongoDB for data, Redis for short-lived state, and Docker for repeatable environments.

Product contextUnderstand why a feature exists before deciding how to build it.
